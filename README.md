# 🚀 NexusHub

### Distributed Device Monitoring & Management System

---

## 📌 Project Overview

**NexusHub** is a centralized management platform designed to monitor and manage distributed hardware devices such as **Digital Signage screens** and **IoT sensors**.

Built with **.NET 8.0** and structured using **Clean Architecture**, the system ensures scalability, maintainability, and clear separation of responsibilities across layers.

---

## ✨ Key Features

### 🧱 Layered Architecture

* Clean separation of concerns
* Structured into:

  * **Core**
  * **Data**
  * **Business**
  * **API**

---

### 🗄️ Database Integration

* PostgreSQL as the primary database
* Fully containerized using **Docker**
* Easy setup and environment consistency

---

### 📡 Real-time Health Monitoring

* Automated device health evaluation
* Based on:

  * Connectivity status
  * Last-seen timestamps
* Uses **Enums** for clear state management

---

### 🔌 API-First Design

* RESTful API architecture
* Fully documented with **Swagger**
* Easy integration with external systems

---

## 🛠️ Tech Stack

* **.NET 8.0 (C#)**
* **Entity Framework Core**
* **PostgreSQL**
* **Docker**
* **Git & GitHub**

---

## 🎯 Goal

To provide a scalable and maintainable platform for efficiently monitoring and managing distributed device networks in real time.
